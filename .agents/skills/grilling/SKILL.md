# Grilling

Read the [project rules](../../../docs/architecture-review.md#project-rules)
and then [the upstream instructions](UPSTREAM.md). Apply them within the task
scope, with the project rules and adaptations below taking precedence.
Resolve upstream references relative to this skill directory.

Follow the upstream rounds and decision-dependency process within the
requested scope. Research code facts before asking the user. Preserve decisions
and authorization already supplied; settle only material open branches.

Wait for answers needed by a dependent design choice. Continue independent
inspection while waiting. Do not turn a scoped review into an exhaustive
interview or infer authorization for implementation from a discussion.
